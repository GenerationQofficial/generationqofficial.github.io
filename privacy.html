Privacy Policy

Last updated: November 6, 2026

This policy explains what the GenQ uploader, a private tool run by GenerationQ ("we", "us"), does with data. The GenQ uploader publishes GenerationQ's own short videos to the Generation Q YouTube channel and reads that channel's statistics.

YouTube API Services

The GenQ uploader uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses it

Only the GenerationQ team uses the GenQ uploader, and only with the Google account that owns the Generation Q channel. It is not offered to the public, and it never signs in to anyone else's account.

What data it accesses

  • Upload access (youtube.upload): to publish videos that GenerationQ created, with their title, description, tags and publish time.
  • Read access (youtube.readonly): to list our own channel's videos and their public numbers (views, likes).
  • Analytics (yt-analytics.readonly): to read our own channel's watch time, views and subscriber changes.

It does not access personal information about viewers, commenters or subscribers, and it does not read private messages.

How data is stored

The sign-in token that Google issues is stored only on GenerationQ's own computer, so the tool can keep working without signing in again. Video statistics are stored in local reports on the same computer, to plan future content. No data is stored on any server run by us.

Sharing

We do not sell, rent or share any data with third parties. Data is only exchanged with Google through the YouTube API Services, to perform the actions above.

Cookies

This website does not use cookies or tracking. The GenQ uploader does not place cookies on any device.

How to revoke access

The account owner can remove the GenQ uploader's access at any time from the Google security settings page: security.google.com/settings/security/permissions. When access is removed, the stored token stops working and can be deleted.

Changes

If this policy changes, we will update this page and the date at the top.
